# 用 Tailscale 远程访问 dsh web — 详细教程

> 适用：Windows 电脑运行 `dsh web`（默认 `127.0.0.1:3080`），手机在 4G / 任意网络远程访问同一套 GUI。
> 版本：DSH `0.1.2-alpha.x` · 插件 `@linxin666/dsh-remote-web-ui` `0.3.x`
> 目标：用 Tailscale 组私有虚拟局域网（tailnet），手机直连电脑，替代 cloudflared 的"公网隧道"。

## 一、方案与原理

- **目标**：Windows 电脑跑 `dsh web`（`127.0.0.1:3080`），手机在 4G / 任意网络远程访问同一套 GUI。
- **原理**：电脑和手机都装 Tailscale，登录同一账号 → 组成私有 **tailnet**（虚拟局域网）→ 手机直连电脑的 Tailscale 地址（`100.x.y.z` 或尾标域名）→ 流量在 tailnet 内传输，**不暴露到公网**。
- **对比 cloudflared**：地址**固定**（不每次重启变）、直连时**不依赖海外中继**、**不暴露公网**（更安全）。代价是两端各装一个 app。

**两个硬前提（必须同时满足）**：

1. `dsh web` 必须监听**非回环**地址（`0.0.0.0`）——否则手机（远程设备）的流量进不了 `3080`。这是最容易漏的一步。
2. 手机和电脑在**同一个 tailnet**（同一 Tailscale 账号）。
3. 首次登录 Tailscale 需要能**出海一次**（有出海能力，开代理登录一次即可，之后直连不用）。

## 二、准备工作

| 项 | 说明 |
|---|---|
| Windows 电脑 | 已跑 `dsh web`，能正常打开本地 GUI |
| 手机 | Android / iOS |
| Tailscale 账号 | 免费个人版（100 设备内） |
| 出海能力 | 仅**首次登录** Tailscale 用；日常直连不需要 |

## 三、电脑端：安装 Tailscale（作为系统服务）

1. 到官网 `tailscale.com/download` 下载 Windows `setup.exe`。
2. 安装时**勾选 "Install as a service"**（作为服务安装 → 开机自启、后台常驻，重启无感）。
3. 安装后登录：会弹出浏览器到 `login.tailscale.com`，用 Google / Microsoft / GitHub 登录（或邮箱 magic link）。**这一步需要能出海**——开代理登录一次即可。
4. 登录成功后验证（PowerShell）：
   ```powershell
   tailscale status
   ```
   - 能看到自己的节点、其它节点，以及自己的 **Tailscale IP**（形如 `100.64.0.12`）。
   - 记下：**电脑 Tailscale IP**（`100.x.y.z`）和**尾标域名**（`<电脑名>.<你的尾缀>.ts.net`）。

## 四、电脑端：让 dsh web 监听 0.0.0.0（关键一步）

默认 `dsh web` 绑 `127.0.0.1`（回环），手机（远程）到不了。要改成 `0.0.0.0`：

**推荐：用插件的「局域网绑定」开关**（它会自动处理防火墙，最省心）：

1. 打开 **设置 → Web 插件 → 远程访问设置**。
2. 打开 **「局域网绑定」（lanBind）** 开关。插件会自动做两件事：
   - 把 bind 钉到 `0.0.0.0`（写 profile patch 的受管块）；
   - **加 Windows 防火墙规则放行 3080**（`netsh`，避免防火墙把 tailnet 流量挡掉）。
3. **重启 `dsh web`**（`0.0.0.0` bind 在下次启动才生效；设置卡会显示 `pendingRestart` 提示，等你重启）。

> 副作用须知：开「局域网绑定」后，**同一物理局域网**（`192.168.x.x`）的设备也能访问 3080（仍受配对保护）。这是"绑 0.0.0.0"的固有结果，Tailscale 访问是叠加在其上的，不是替代。

备选（手动，不自动加防火墙）：用 `dsh web --host 0.0.0.0` 启动。

## 五、手机端：安装并登录 Tailscale

1. 应用商店装 **Tailscale**（iOS / Android）。
2. 打开 app，**用与电脑同一个 Tailscale 账号登录**（同样首次需出海一次）。
3. 登录成功 → 手机也获得一个 `100.x.y.z`。
4. 验证：app 里能看到电脑节点；或手机 `ping <电脑Tailscale-IP>` 通。
5. **Android 关键**：给 Tailscale「允许后台运行 + 电池优化白名单」，否则系统杀后台会断。iOS 一般无需额外设置。

## 六、让二维码指向 Tailscale 地址（二选一）

让手机扫的二维码指向 `100.x.y.z:3080`（手机经 tailnet 可达）：

- **方法 1（最确定，推荐）**：在插件设置里把 **「公网地址」（publicBaseUrl）** 填成：
  ```
  http://<电脑Tailscale-IP(100.x.y.z)>:3080
  ```
  或尾标域名 `http://<电脑尾标>.<尾缀>.ts.net:3080`。
  二维码会**强制**基于这个地址构造（字段名虽叫"公网"，填 Tailscale 内网地址同样有效——它只是"手机可达的地址"）。
- **方法 2（省事，看面板）**：不开 publicBaseUrl，只开「局域网绑定」后，面板二维码会**自动列出所有非回环地址**（物理局域网 IP + **Tailscale 的 `100.x.y.z:3080`**）。在面板里**认准 `100.x.y.z:3080` 那个**给手机扫（别扫 `192.168.x.x` 那个，除非手机也在同一物理局域网）。

> 为什么 `http`（非 https）没问题：插件设计上就支持非安全上下文（LAN HTTP），手机浏览器会提示"不安全"但能正常打开配对页面。

## 七、配对（手机扫电脑二维码）

1. 电脑端：点侧边栏**电话图标**打开「远程访问」面板。
2. 手机打开相机 / 浏览器扫码（或手动输入 URL），扫**指向 `100.x.y.z:3080` 的二维码**。
3. 走配对流程（页面接受 → 配对完成）。
4. 成功后，手机即可通过 tailnet 访问 dsh web，**地址固定、长期有效**（不像 cloudflared 每次重启换地址）。

## 八、保持在线（重启 / 常驻）

| 端 | 要点 |
|---|---|
| 电脑 · Tailscale | 服务开机自启（装时勾了 service），重启无感、地址不变 |
| 电脑 · dsh web | **要能自启**，否则重启后 3080 没服务。用 Windows「任务计划程序」开机运行 `dsh web`，或用 NSSM 注册成服务，或放启动脚本 |
| 电脑整机 | **别睡眠**（睡眠会断 tailnet） |
| 手机 · Tailscale | app 后台常驻（Android 给白名单）；重启后自动重连、地址不变 |

## 九、故障排查

| 现象 | 常见原因 | 解决 |
|---|---|---|
| 面板只有"需局域网绑定"提示、没二维码 | dsh web 还没绑 `0.0.0.0` | 开「局域网绑定」+ **重启 dsh web** |
| QR 有地址，手机扫了打不开 | 两端不在同一 tailnet / Tailscale 没连上 | 确认两端同账号；两端都跑 `tailscale status` 看对方是否在线 |
| 手机能开页面但配对 403 | 防火墙挡 3080 / host 不被信任 | 用「局域网绑定」（自动加防火墙）；或确认 publicBaseUrl 填的是 `100.x`/尾标 |
| 电脑重启后就连不上 | dsh web 没自启 | 给 dsh web 配开机自启 |
| 手机用一会儿就断 | Android 杀后台 | 给 Tailscale 后台/电池白名单 |
| 想知道走直连还是中继 | NAT 打洞情况 | 任一端 `tailscale ping <对方尾标>`：`direct`=直连（日常不用出海）；`via DERP`=中继（需能连海外，或自建境内 DERP 中继） |

## 十、安全说明

- Tailscale 是**私有 tailnet**，**不暴露公网** → 比 cloudflared（公开 `trycloudflare`）更安全。
- **配对后的手机 = 完全控制凭据**，仍要妥善保管手机（丢手机等同丢权限）。
- 保持 **`requirePairingForLan`（默认开）**：任何非回环访问都要配对。
- 不用的设备：在面板里 **revoke / stop** 撤销该设备会话。

## 附：Tailscale vs cloudflared 对照

| | cloudflared | Tailscale |
|---|---|---|
| 地址 | 每次重启变 | 固定（`100.x`/尾标） |
| 是否暴露公网 | 是（trycloudflare） | 否（私有 tailnet） |
| 依赖出海 | 每时每刻（连 Cloudflare） | 仅首次登录 + 走中继时 |
| 配置量 | 一个开关 | 两端装 app + 开「局域网绑定」 |
| 最适合 | 偶尔用 | 长期手机远程 |

## 最小动作清单（按顺序）

1. 电脑装 Tailscale（服务）并登录 → 记下 `100.x.y.z`
2. 手机装 Tailscale，同账号登录
3. 插件设置：开「**局域网绑定**」
4. 插件设置：**publicBaseUrl** 填 `http://<100.x.y.z>:3080`
5. **重启 dsh web**（自行操作）
6. 面板扫 `100.x` 那个二维码 → 手机配对
